# Helena Mo · Creative Embedded System Design

A course portfolio for project documentation throughout the class.

Website: https://helenamoisme.github.io/

## Updating projects

Replace the clearly marked upcoming cards in `index.html` with real project titles and descriptions as the course progresses. Add a documentation page for each project, including sketches, components, code, tests, photos, and reflections, then link its card to that page.

## Preview locally

```bash
python3 -m http.server 4173
```

Open http://localhost:4173/.

## GitHub Pages

This repository is named `helenamoisme.github.io`. In repository **Settings → Pages**, set the source to **Deploy from a branch**, branch `main`, folder `/ (root)`. The public URL is https://helenamoisme.github.io/.
