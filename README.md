# Helena Mo — Personal Website

A static personal website with no build step.

**Website:** https://helenamoisme.github.io/

## Local preview

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173/.

## Publishing

This repository is named `helenamoisme.github.io`. GitHub Pages deploys from the `main` branch and the repository root.

## Editing

Update the biography, projects, publications, and links in `index.html`. The profile photo is in `assets/helena-mo.jpg`; the visual design is in `styles.css`.
